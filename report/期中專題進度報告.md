### 一、工作與進度報告： 

目前開發進度已涵蓋系統架構的四大核心層級，詳細已完成工作與功能如下：

**1. 資料基礎建設層 (Data & Database)**
*   **資料庫架構建立與部署**：完成核心表格設計（Courses 等），支援一門課多時段儲存以及 JSON 格式的個人化標籤存取。配合 Aiven MySQL 雲端環境建置，支援遠端連線，並已通過手動腳本驗證雲端資料寫入功能正常。
*   **API 標準化**：同步發布 HackMD API 文件，標準化各資料表欄位命名與前後端傳遞的資料型態。
*   **本地環境測試**：建立本地測試與開發環境前置作業，並已初步了解與建置 Docker 容器化規劃。

**2. Agent 核心控制層與 API 開發 (LMS Agent / 後端 API)**
*   **伺服器建置**：完成 Node.js 後端伺服器架設，打通 Input / Response API 通道。
*   **記憶體模組 (Memory)**：實作「短期記憶」（記錄當次聊天上下文以利對話接續）與「長期記憶」（儲存使用者偏好、已修學分與時段限制）的管理模組。
*   **提示詞工程 (Prompt Manager)**：能成功將使用者輸入的自然語言與個人化限制，包裝轉換為 LLM 系統能理解之 Prompt。
*   **推理與決策引擎 (LLM Core)**：成功開發後端 Agent 核心，包含自然語言意圖解析器（Intent Parser），能精準判讀使用者排課需求並決定呼叫對應的 Skills。

**3. 技能與工具層 (Skills / Tools)**
*   **Skill 1 (課程資料查詢)**：開發對接資料庫查詢全校完整課程資訊的功能模組。
*   **Skill 2 (評價與涼度檢索)**：開發用於檢索重點評論摘要與標籤的模組框架（準備後續套用爬蟲資料）。
*   **Skill 3 (排課演算法 CSP)**：完成「限制滿足問題」的排課引擎！並進階導入「貪婪法則 + 局部改進 (Greedy + Limited Backtracking)」演算法，成功解決複雜課表組合的效能問題，將生成無衝突課表的時間縮減至 100 毫秒以內。

**4. 互動展示層 (Web User / 前端 UI/UX)**
*   **Figma 介面設計**：完成了包含「系統對話輸入區」與「視覺化課表展示區」大致上的排版佈局，目前正在進行 Prototype 的拉線與動線模擬。
*   **前端開發**：已開始將介面轉化為程式碼，開發具備高互動性的課表展現與個人化表單輸入等區塊。
