# 個人化課表規劃推薦系統 - 系統操作指南 (System Operation Guide)

歡迎使用「個人化課表規劃推薦系統」。本系統整合了先進的大型語言模型 (Google Gemini API) 與本地 Constraint Satisfaction Problem (CSP) 排課演算法，讓您能用語音或自然語言對話的方式，輕鬆搞定每學期的選課地獄！

本指南將引導您如何與系統互動，以及運用各種關鍵句型觸發系統強大的「技能 (Skills)」。

---

## 🚀 核心功能與操作情境範例

系統搭載了 5 大核心 Agent 工具，只要您在聊天對話框中用自然的口吻輸入需求，AI Agent 就會自動為您分配策略、呼叫工具庫並為您完成任務。

### 1. 🔍 搜尋特定課程 (Course Search)
當您確定了想修的系所、必選修或是星期幾的特定時間段時，可以直接口語化發問。Agent 會抓取學校課程資料庫並過濾條件。

* **使用範例：**
  - 「幫我找找看資工系的選修課有哪些？」
  - 「星期三下午有沒有通識課？」
  - 「我想找陳建宏老師開的課。」

### 2. 📊 查看評價與涼度 (Review Insights)
選課前看評價是必備動作。系統整合了 Dcard 爬蟲與情感分析技術，您不需要再去論壇爬文，直接詢問系統就能得知該課程的「實際推薦度」與「難易度」。

* **使用範例：**
  - 「軟體工程這堂課的評價如何？」
  - 「機器學習會不會很難過？」
  - 「查一下資料結構的心得摘要。」

### 3. 🏖️ 尋找營養學分 / 涼課推薦 (Easy Courses)
想補足學分又不想太累？Agent 內部維護了一份「全校涼課排行榜」，可以直接根據好評率與低難度篩選課程。

* **使用範例：**
  - 「推薦我幾堂超好過的涼課！」
  - 「有沒有推薦的營養學分可以修？」
  - 「列出全校前五名的涼課。」

### 4. ⚙️ 設定個人排課偏好 (Preferences)
每個人的作息不同，您可以請 Agent 記住您的個人習慣。這些限制條件將成為後續為您自動排課時的長久記憶基準 (Long-term Memory)。

* **使用範例：**
  - 「我這學期不想排早八的課。」
  - 「幫我設定晚上不排課，而且學分最多只要 19 學分。」
  - 「我比較喜歡集中排課，請盡量幫我排滿。」

### 5. 📅 一鍵智能排課演算法 (Auto-Scheduler)
這是系統最強大的功能。Agent 會在理解您的限制與必修條件後，自動執行排課演算法，為您算出完全不衝堂、且最符合您生活作息的完美課表。

* **使用範例：**
  - 「根據我的偏好，幫我排出一套完整的課表。」
  - 「我想把剛才推薦的涼課塞進課表裡，幫我重排一次。」
  - 「幫我排滿至少 18 學分，並且星期五希望能放假 (不排課)。」

## 🤖 互動進階密技：複合型對話 (Agentic Workflow)

得益於我們在後端實作的 **ReAct (Reasoning and Acting)** 機制，Agent 可以在一句話內幫您連續執行多個動作！您不需分段下指令，請勇敢地一次提出複雜需求：

> **👨‍🎓 您：**「我這學期想修 20 學分，且絕對不要早八！請先幫我找兩堂評價最高的資工系選修課，然後直接幫我連同必修一起排出一份最佳課表。」
> 
> **🤖 系統內部行為解析：**
> 1. 觸發 `update_preferences`，設定 `noMorningClasses = true`, `targetCreditsMax = 20`。
> 2. 觸發 `check_reviews` 與 `search_courses`，分析資工系選修課的難易度並挑選最佳兩堂。
> 3. 將選好的課程納入白名單，觸發 `generate_schedule` 演算法。
> 4. 最後，用流暢的中文將排好的結果呈現給您，卡片區也會同步繪製出精美的課表畫面！

## 🛠️ 環境與啟動指示 (開發者準備)

如果您是在本地啟動此系統進行操作：

1. **環境變數確認：** 請確定 `server/.env` 檔案內已經設定了正確的 `GEMINI_API_KEY`。
2. **啟動後端：** 於 `server` 目錄執行 `npm run dev`，確認出現 `🚀 課表規劃推薦系統後端已啟動` 等字樣。
3. **啟動前端：** 於 `client` 目錄執行 `npm start` (或相應腳本) 啟動 React/Vue UI 頁面。
4. 在瀏覽器中進入系統首頁後，即可在文字對話框中輸入上述範例開始體驗！
