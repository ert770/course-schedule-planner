# 系所簡稱對照表（待確認）

## 用途

`Course_Sections` 沒有「這門課屬於哪個系所」的欄位，只有班級名稱（API 對應到 `course.department`），例如 `資訊三甲`、`會計碩一`。而 `User_Profiles.department` 存的是系所全名，例如 `資訊工程學系`。

排課時必須先把候選課程縮到「這位學生的系所與年級」，否則全校 2094 筆必修會被當成每位學生的必修（見路線圖 `#13`）。本文件即為兩者的對照依據。

## 狀態

下表由 562 個班級名稱反推而來，2026-08-01 經使用者確認 22 項、修正 6 項。

| 標記 | 意義 |
| --- | --- |
| ✅ | 使用者已確認 |
| ✏️ | 使用者已修正（原推測有誤） |
| ⬜ | 尚未確認，**包含原文件未標問號但同樣未經驗證的項目** |

## 重要：簡稱與系所不是一對一

確認過程中發現兩組**多個簡稱指向同一系所**的情形，實作時不可假設一對一：

| 系所 | 對應簡稱 | 差異 |
| --- | --- | --- |
| 機械與電腦輔助工程學系 | `機電`（大學部）、`機械`（碩士班） | **同一系所，學制不同簡稱不同** |
| 室內設計進修學士班 | `室內設計`、`室設進修` | **同一單位，兩種寫法並存** |

因此對照必須是「系所全名 → 簡稱**清單**」，而非單一簡稱。以機械與電腦輔助工程學系的學生為例，其可修課程同時分布在 `機電一甲`～`機電四乙` 與 `機械碩一`／`機械碩二` 兩組班級中，只比對其中一個簡稱會漏掉另一組。

另需注意 `資工` 只出現於國際學程班級（SFSU、Monash），**資訊工程學系的一般班級簡稱是 `資訊`**。

## 是否可用程式推導

**不建議。** 簡稱與全名之間沒有一致的構詞規則：

| 簡稱 | 全名 | 關係 |
| --- | --- | --- |
| 資訊 | 資訊工程學系 | 前綴相符 |
| 資工 | （國際學程專用） | 前綴相符但**指向不同對象** |
| 合經 | 合作經濟暨社會事業經營學系 | 取首字與中段字 |
| 纖複 | 纖維與複合材料學系 | 取首字與中段字 |
| 水利資保 | 水利工程與資源保育學系 | 跨詞取字 |
| 機電 | 機械與電腦輔助工程學系 | 取兩個中段字 |
| 機械 | 機械與電腦輔助工程學系（碩士班） | **與 `機電` 同系所，取字方式不同** |

`機電` 與 `機械` 這組尤其說明問題：兩者取字方式不同、字面不相似，卻指向同一系所；而 `機械` 字面上看似獨立的「機械工程學系」，實際上並不是。任何基於字面相似度的推導都會出錯。

必須以人工確認的對照表為準。
