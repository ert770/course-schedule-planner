# 系所簡稱對照表（待確認）

## 用途

`Course_Sections` 沒有「這門課屬於哪個系所」的欄位，只有班級名稱（API 對應到 `course.department`），例如 `資訊三甲`、`會計碩一`。而 `User_Profiles.department` 存的是系所全名，例如 `資訊工程學系`。

排課時必須先把候選課程縮到「這位學生的系所與年級」，否則全校 2094 筆必修會被當成每位學生的必修（見路線圖 `#13`）。本文件即為兩者的對照依據。

## 狀態

**待確認。** 下表由 562 個班級名稱反推而來，尚未經校方資料驗證。標示 `?` 者為推測，需人工確認。

## 班級名稱結構

解析規則：`[系所簡稱][學制][年級][班別]`，共解析出 125 個簡稱。

| 元素 | 值 | 範例 |
| --- | --- | --- |
| 學制 | 學士（省略）／碩／博／進修／學士後 | `資訊三甲`、`資訊碩一`、`中文博三` |
| 年級 | 一二三四五 | `資訊三甲` 為三年級 |
| 班別 | 甲乙丙丁／合（合班）／A~C班 | `資訊三甲`、`資訊三合` |
| 國際學程 | 括號標示合作學校 | `資工一(SFSU)`、`商學一(UQ)` |

## 需要確認的問題

1. **A 表中標示 `?` 的全名是否正確？** 共 40 餘項為推測。
2. **`User_Profiles.department` 的值域為何？** 目前只有一筆且含字面單引號（`'資訊工程學系'`），無法得知完整命名規則。
3. **B 類共同科目如何判定適用對象？** 例如 `軍訓(一年級)` 只適用一年級，`大二英文綜合班` 只適用二年級，但 `體育選修` 可能不限年級。
4. **C 類學院綜合班需要「系所 → 學院」對照**，例如資訊工程學系屬於資電學院。
5. **`核心必修綜合班`（52 門）的適用對象為何？**
6. **D 類英語授課班是否為獨立學制？** 例如資訊工程學系的學生是否可能被編在 `資電英A班`。

## 是否可用程式推導

**不建議。** 簡稱與全名之間沒有一致的構詞規則：

| 簡稱 | 全名 | 關係 |
| --- | --- | --- |
| 資訊 | 資訊工程學系 | 前綴相符 |
| 資工 | （國際學程專用） | 前綴相符但**指向不同對象** |
| 合經 | 合作經濟暨社會事業經營學系 | 取首字與中段字 |
| 纖複 | 纖維與複合材料學系 | 取首字與中段字 |
| 水利資保 | 水利工程與資源保育學系 | 跨詞取字 |

必須以人工確認的對照表為準。
