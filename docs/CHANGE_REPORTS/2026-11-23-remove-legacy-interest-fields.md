## 追加：太常見的主題（Python 等）怎麼排（2026-11-23 使用者決定）

- **決定**：問答**不開放**勾 Python 和其他太常見的標籤（too_common）。想排的話，直接跟 AI 助理說，例如「這次想排 Python 的課」；Agent 會把它當成這次排課的關鍵字，用「標籤以它開頭」的規則比對課程。這條路原本就能用，不需要改排課程式。
- **為了避免使用者誤會，在系統裡加上說明**：
  - **問答細項頁**（`InterestQuestionnaire.jsx`，`#interest-quiz-common-topics`）：「Python 這類很常見的工具或技能不在主題選項裡。想排的話，排課時直接跟 AI 助理說，例如『這次想排 Python 的課』。」
  - **Agent 提示詞**（`promptService.js`）：使用者想長期保存這類主題時，Agent 要說明問答沒有這類選項，請他每次排課時直接說。`prompt.test.js` 已補上斷言。
- **驗證**：
  - 前端 lint、build 通過；`prompt.test.js` 63 項全過。
  - 瀏覽器（D0009002）：從設定頁進入問答的本系細項頁，提示有顯示，有截圖；過程中沒有存檔，資料沒有變動。
  - 聊天說「以後我都想排 Python 相關的課，幫我存成長期興趣」，Agent 回答：「『Python』不在課程主題問答的長期興趣選項中，因此無法直接存成長期興趣。之後每次排課時，你可以告訴我『這次想排 Python 相關課程』……」，資料也沒有被寫入。

## 追加：興趣導向方案消失的原因與說明文字（2026-11-23）

**驗證**：用 `D0009002`、`D0009005`、`D0009007`、`D0009008` 各跑四種條件（全開、關 S_tag、關 s_vec、兩個都關），只讀資料、不寫入。

- **D0009002**：
  - 全開時，綜合方案的興趣程度是 0.143（命中 2 門），興趣導向方案沒有產生。
  - 關掉 S_tag 或 s_vec 任一個時，綜合方案降到 0.071，興趣導向方案出現（0.143）。
  - 這位學生在學分、時段、必修限制下，最多只排得進 2 門勾選主題的課。候選池有 13 門命中課，但同時排得進課表的只有 2 門。
  - S_tag 或 s_vec 讓綜合方案自己就達到這個上限，興趣導向方案無法再高出門檻。
- **D0009008**：情況相同。兩個都關時，綜合方案 0.071，興趣導向方案 0.143。
- **D0009005、D0009007**：四種條件下都只有 1 份方案，原因是勾選主題少、命中課也少，和 S_tag／s_vec 無關。
  - D0009007 的代勾「AI 應用 → AI工具」命中的是「卓越領導力」（GEIG2188，翟本瑞老師，114 下學期唯一一班，主題標籤含「AI工具」）。
    - 使用者確認（2026-11-23）：這門課會教怎麼用 AI 提升自我能力，例如老師用自己做的 agent 把最新的 AI 影片與文章摘要成一張圖，以及 agent 搭配逆向工程。
    - 所以這筆代勾是對題的，予以保留。

**說明文字**（使用者決定）：興趣導向方案的原因是 `axis-threshold-infeasible`，而且綜合方案已有興趣命中時，標上 `detail: base-already-best-interest`，前後端都顯示「綜合方案已經是最符合你興趣的組合，再排一份只會是重複的課表」。

- **改動的檔案**：
  - `scheduler.js`：新增並匯出 `collapseDetailFor()`；
  - `PlanSwitcher.jsx`：`DETAIL_TEXT` 加上新的說明；

- **驗證**：
  - D0009002 的排課回應裡，`planDiversity.collapsed` 的興趣導向方案帶有 `detail: base-already-best-interest`，`warnings` 也換成新的說法。
