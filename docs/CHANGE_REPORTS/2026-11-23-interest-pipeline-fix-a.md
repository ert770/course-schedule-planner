# 修法 A：AI 聊天這次有給關鍵字時，興趣軸只用這次的關鍵字

- 日期：2026-11-23
- 背景：
  - `cc4cddc` 讓問答勾選的標籤進入排課的興趣軸（ADR-031）。
  - 當時的 Agent 情境比較顯示，有勾選的帳號，聊天關鍵字的命中率下降。
  - 使用者決定照修法 A 修。
- 修法 A 的規則：這次請求自己帶了非空的 `interests` 或 `preferredKeywords` 時，`interestTagIds` 為空陣列。
  - 這和「這次的 `interests` 蓋掉已存的 `interests`」是同一條規則。
  - 只影響這一次的興趣軸。S_tag、s_vec、探索卡仍讀已存的勾選，也不寫入任何資料。

### 更正：先前報的「聊天關鍵字被稀釋」主要是資料隨時間改變

`cc4cddc` 的報告寫 D1249697 的聊天關鍵字命中率從 0.131 降到 0.095。但當時拿來比的舊版是幾個小時前跑的。

這次**現在**重跑舊版，同樣的關鍵字情境也是 0.095。例如「機器學習」，幾小時前是 0.5，現在是 0.25。所以那次的下降主要來自帳號資料隨時間改變（標籤興趣快取、互動事件、時間衰減），不是程式造成的。

**教訓**：前後比較要在同一時間跑兩個版本。全帳號報告當時新舊版是同時跑的，不受這個問題影響。
