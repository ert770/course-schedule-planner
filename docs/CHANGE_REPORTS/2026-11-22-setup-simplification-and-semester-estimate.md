# 偏好設定整併與剩餘學期推算

日期：2026-11-22

## 變更範圍

- `client/src/pages/SetupPage.jsx` 移除 MBTI、手填剩餘學期與主要修課路徑的輸入及送出欄位。課程興趣頁保留新版主題問答與「其他興趣」。歷史修課回饋入口移至基本資料，沿用原個人化同意與操作。
- `client/src/pages/InterestExplorationPage.jsx` 移除使用者主要修課路徑的摘要。既有路徑資料與計分規則繼續沿用。
- `server/src/data/graduationPlanning.js` 依有效的修課學年學期與可核對的入學起點推算四年制剩餘學期。正式入學學年有效時，須有位於入學至當期的有效歷史紀錄。缺入學學年時，採與當前年級相符的入學上學期紀錄作為起點。其餘情況依當前年級與開課學期回退，資料不足時回傳 `unknown`。推算包含當期，忽略既有手填值。舊欄位可照常讀寫供相容，資料庫無須遷移。
- `server/test/graduationPlanning.test.js` 加入或更新入學資料推算、不完整歷史回退、舊手填值與配額案例。
- `docs/API_SPEC.md`、`docs/DATA_SCHEMA.md`、`docs/SCHEDULING_LOGIC.md` 同步記錄相容欄位、來源值、推算與回退。核對 roadmap 進度總覽的狀態與相依，第 23 項其餘校方規則資料仍待補。
