## 1. 結論

1. **v2 產生完成**：2,004 門課，`text-embedding-3-large`、3,072 維，實際用量 **2,064,084 tokens**
   （盤點時的保守上限是 527 萬）。送出的是課名、標籤、課程簡介與組員匯入的大綱文字，不含任何使用者資料。
2. **排課：v1 與 v2 完全相同**（API 與畫面都是 4 門課、9 學分、同樣的課）。排課本來就不使用文字向量，
   這是預期中的對照組，證明 v2 沒有副作用。
3. **探索「依你的修課與興趣」：完全相同**。這個模式用標籤向量 `s_vec`，不用文字向量，也是對照組。
4. **探索「從一門課出發／語意相似」：小幅變動，看不出變好。** 8 個起點、16 份清單中：
   - 9 份完全相同、4 份同一批課只是順序不同、**3 份各換掉 1 門課**。
   - 換掉的 3 門，我判斷 1 門變差、1 門略差、1 門差不多（第 3 節）。
5. **目前啟用的仍是 v1**。v2 已另存，要啟用只需換檔（第 5 節），不必重開伺服器。
   建議**暫不啟用 v2**：成本已付，但沒有證據顯示推薦變好。

## 3. 探索「語意相似」逐項比較

| 起點 | 系外選修 | 通識 |
| --- | --- | --- |
| Web程式設計 | 相同 | 相同 |
| 人工智慧導論 | 同一批，順序不同（系統資料分析與建模 5→3） | 相同 |
| 資料庫系統 | 同一批，順序不同 | 相同 |
| 資訊與網路安全 | 相同（0 門） | 相同 |
| 計算機演算法 | 同一批，順序不同（機器學習升到第 1） | 相同 |
| **Python程式設計** | **換 1 門**：建模與模擬 → **投資組合分析**（財務金融系，共同標籤只有 Python） | 相同 |
| **決策與賽局** | 相同 | **換 1 門**：策略理論與中國崛起 → **人物與中國歷史** |
| **生態環境保育** | 同一批，順序不同 | **換 1 門**：衛星導航-永續地球 → **從空間看世界** |

我的判斷：

- Python → 投資組合分析：**變差**。這門課只是用 Python 做財務分析，和「Python程式設計」的學習內容距離較遠；
  被換掉的「建模與模擬」比較相關。
- 決策與賽局 → 人物與中國歷史：**略差**。「策略理論」與賽局的關係比歷史人物更直接。
- 生態環境保育 → 從空間看世界：**差不多**。兩門都只和地理、環境沾邊。

相似度數值整體略降（例：Web程式設計的第一名 0.403 → 0.360），大綱文字較長、主題較雜，
讓課與課之間的差異被稀釋。另有 1,050 門課超過 1,800 字上限而被截斷，截斷位置不一定保留最有代表性的內容。
