# 統一加選與關注按鈕

日期 2026-11-25

## 修改內容與影響範圍

- `client/src/components/CourseCard/CourseActions.jsx` 共用關注、加選及取消加選操作。關注成功時愛心變紅並跳動，加入成功時原按鈕顯示綠色「已加入」，失敗原因顯示在對應課程旁。取消加選沿用既有確認與避開流程。
- `client/src/App.css` 共用按鈕、滑鼠移入、動畫和提示樣式。系外與通識探索、畢業進度頁的按鈕在窄畫面可換行，並遵循減少動態效果的設定。
- `client/src/pages/SearchPage.jsx` 搜尋結果及我的關注使用共用元件。
- `client/src/pages/ExplorePage.jsx` 系外與通識的班次都可關注及加選，操作回饋留在班次旁。加選仍帶入探索來源。
- `client/src/pages/GraduationPage.jsx` 顯示帳號的實際關注清單，相關按鈕與補救建議中的正式班次使用同一份課表和關注狀態。只有文字的提醒維持資訊顯示。

畢業進度原先獨立保存在瀏覽器的選課清單未接入課表。新流程從操作時使用首頁的課表狀態，既有獨立清單未合併，以免把原本的示例資料當成實際班次。

## 驗證

- Chrome A/B 對照中，原版探索會在頁首顯示加選訊息，畢業進度會跳出瀏覽器提示。修改後，搜尋、系外與通識探索、畢業進度都顯示相同的愛心動畫、滑鼠移入樣式、加選回饋與課程旁衝堂提示。
- 驗證搜尋取消加選、探索加選後回搜尋查到狀態、畢業建議的關注同步到同頁清單、從清單取消加選可開啟共用確認視窗，以及畢業頁加選後回首頁看得到課程。窄畫面及減少動態效果模式一併驗證。瀏覽器 console 未發現錯誤。
- 瀏覽器使用隔離測試課程及帳號資料，衝堂以現有後端驗證函式判斷。
- 前端 lint、build、後端入口語法檢查與 `git diff --check` 通過。完整測試 1,989 筆通過、14 筆跳過、0 筆失敗。
