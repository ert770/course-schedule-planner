## 4. 同義詞合併候選

### 4.1 做法

沿用 2026-10-08 13 組語意別名的機制（`interestTagAliases.json`：別名 → 標準標籤）。

1. 全部 6,769 個標準標籤（含只出現在一門課的）以 `text-embedding-3-large` 計算名稱向量，
   新增 4,598 個名稱的 embedding（27,609 tokens），與階段 2 共用快取。
2. 候選 = 名稱相似度 ≥ 0.80 的前 10 名，加上字面規則（英語／英文、智能／智慧、網絡／網路、軟件／軟體、
   信息／資訊、變換／轉換、器械／器材、批判性思維／批判思維、空白與標點）：共 1,537 組。
3. 每組問 `gpt-5.6-luna` 兩次「是否為可互換的同義詞」。提示中明確排除上下位、只是相關、程度不同、範圍不同。
4. 兩次都同意的配對以聯集合併成群組，群組內課數最多的當標準標籤。

只送標籤名稱，不含使用者資料。對資料庫不讀也不寫。

### 4.2 結果

| 項目 | 數量 |
| --- | --- |
| 候選配對 | 1,537 |
| 兩次都判同義 | 455 組 → 366 個群組、424 個別名 |
| 一次同義一次不同義（需人工判斷） | 60 組 |
| 最大群組 | 6 個標籤（智慧交通 ← 智慧運輸、智慧型運輸系統、智能交通、智能交通系統、智慧運輸系統） |

例子：人工智慧 ← 人工智能；城市規劃 ← 都市計畫、都市規劃；統計學 ← 統計；資訊安全 ← 資安；
商業英語 ← 商用英文、商務英語、商業英文、商用英語、商務英文；批判性思維 ← 批判思考、批判性思考、批判思維。

我看起來有疑慮、建議你特別看的：職場倫理 ← 專業倫理、職業道德（範圍不完全相同）；
機電工程 ← 機電；統計學 ← 統計。

### 4.4 核准後的套用流程（尚未執行）

1. 把核准的配對寫入 `server/src/data/interestTagAliases.json`。
2. 重跑 `server/scripts/importInterestTagCatalog.py` 重建 `interestTagCatalog.json`。標籤 ID 會改變，
   匯入腳本會拒絕沿用舊的資格快照，所以要：
3. 用 `interestTagEligibilityReport.js` 依當學期課程重算資格（課數、單課、常見主題），並提升目錄版本。
   有些原本只出現在一門課的標籤，合併後會變成可跨課比對。
4. 重算受影響的資料：階段 2 的標籤相近表、降權名單（ID 對應到標準標籤）、評估腳本。
5. **對 `s_tag` 的影響**：目錄版本改變後，已存的 `Learned_Tag_Interests` 會因版本不符而重算；
   舊事件快照裡被合併掉的標籤 ID 不再對應任何課程，那部分證據會失效。這是正式路徑的改動，
   要跑完整測試與瀏覽器 A/B。
