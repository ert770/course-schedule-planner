## 影響範圍

課表首頁的聊天助理在送出當下顯示實際帶入的課數及避開項目，移除等待首筆進度時的「思考中」。同一則摘要接著呈現查詢條件及已取得的候選，再顯示正式文字回答。換課未通過完整課表驗證時顯示原因，保留原課表。

## 驗證

- 前端 build、lint、151 個後端 JavaScript 檔案的語法檢查及 `git diff --check` 通過。
- 以允許本機 HTTP 連線的環境執行 `CI=true npm test`，共 1,991 項，1,977 通過、14 略過、0 失敗。CI 模式沿用專案既有的模型測試略過設定。
- 本環境未提供 `preview_start`，使用隔離 Vite 與固定資料 API 在 Chrome 操作首頁。輸入「把人工智慧入門與省思換成一門星期一的通識課」與「好，取消」，確認活動摘要顯示偏好已保存、查詢週一通識並沿用不排早八，且候選班次在正式回答前已顯示。
- 同一份固定課表對照衝堂與成功。驗證期間無成功訊息，原課仍在課表。衝堂時原課保留並顯示原因。通過時課表已由「人工智慧入門與省思」換成「台灣考古學與原住民」，此時畫面顯示換課成功。
- 確認零筆結果可展開查看排除原因，純問答正常回覆，模擬串流中斷時顯示中斷訊息並保留課表。成功及衝堂對照期間 console 無錯誤或警告，模擬斷線出現預期的錯誤記錄。
- 固定回應驗證用於可控延遲及失敗對照。後端自動測試另行驗證真實 Express 聊天路由。

### 真實模型與 MySQL 驗證

- 首次真實驗收發現首筆後端進度出現前仍短暫顯示「思考中」。修正後在 Chrome 重跑三輪，送出換課需求後、後端核對前已顯示「本次帶入目前課表的 4 門課」。後端核對後，摘要列出待替換課與已存時段偏好。
- 同意取消星期一排空並要求繼續查找後，摘要顯示查詢週一通識、沿用不排早八。正式回答前已顯示第一個候選「台灣考古學與原住民」，週一第 3～4 節。正式回答回報找到 29 個可替換班次，並列出前 10 個。
- 選擇第一門後，候選資格檢查通過時，原課仍在左側課表且成功訊息尚未出現。最後課表換入新課、移除原課，才顯示「衝堂檢查通過，課表已更新」。Chrome console 無錯誤或警告。
- 清除測試新增的本次避開，重新載入後比對，左側課表與測試前一致，偏好恢復為不排早八和涼課優先。
- 驗收使用本機啟動的真實 Express、MySQL 及 OpenAI Responses API。驗收期間以環境變數關閉協同過濾的共現表背景工作。
