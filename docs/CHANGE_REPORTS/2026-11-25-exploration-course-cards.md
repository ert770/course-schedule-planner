# 探索卡片先顯示推薦理由並支援點卡查看

日期 2026-11-25

## 修改內容與影響範圍

- `client/src/pages/ExplorePage.jsx` 讓「依你的修課與興趣」和「從一門課出發」共用卡片排版，先顯示共同主題及相近理由，再顯示各班的修別、教室、教師、學分、年級及時段。
- 點卡片開啟既有詳情視窗，點個別班次則顯示該班的先修條件與課程說明。移除獨立的「詳情」按鈕，班次和課名保留鍵盤操作。關注和加選仍使用共用按鈕，從探索加選的事件來源延續原設定。
- `client/src/App.css` 提供課名與班次的點擊和鍵盤焦點樣式，長地點名稱與課程資訊可在窄畫面換行。

## 驗證

- Chrome A/B 對照原版必須使用「詳情」按鈕，新版在兩種探索模式中可以直接點卡片或個別班次。
- 驗證跨系與通識、單班和多班、推薦理由在資料列上方、鍵盤開啟班次、關注和加選只操作該班、不連帶開啟詳情，以及 390 px 窄畫面的資料換行。使用隔離測試資料，console 無錯誤。
- 前端 lint、build、後端入口語法檢查與 `git diff --check` 通過。完整測試 1,989 筆通過、14 筆跳過、0 筆失敗。
