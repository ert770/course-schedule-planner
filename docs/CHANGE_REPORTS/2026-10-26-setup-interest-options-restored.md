# 設定頁恢復「主要修課路徑」「想接觸的課程主題」選項與「重新探索課程主題」按鈕

- 日期：2026-10-26
- 起因：使用者以 Persona 1 打開設定頁，「感興趣的課程方向」只剩自由輸入框，沒有任何選項。

## 原因

2026-10-11 的 PR #27（前端介面瘦身）從 `SetupPage.jsx` 移除了：

- 「主要修課路徑（單選）」按鈕；
- 「想接觸的課程主題（可複選）」按鈕，資料來自 `GET /api/courses/interest-options`（依系所、年級、班級列出主題與候選課數）；
- 設定頁底部的「重新探索課程主題」按鈕。移除後，只有第一次完成設定時會自動進入興趣卡面，已設定過的使用者沒有任何入口，
  但卡面頁仍寫著「之後可從偏好設定重新探索」。

後端 API 與前端 `coursesAPI.getInterestOptions()` 仍在，只是畫面不再呼叫。已存的修課路徑與興趣仍會被讀進來並在存檔時原樣送出，
但使用者看不到、也改不了；區塊標題卻顯示「興趣方向已設定」。

## 修改

`client/src/pages/SetupPage.jsx`：依使用者要求，把 PR #27 之前的這兩組選項原樣加回「感興趣的課程方向」區塊
（狀態、讀取選項的 effect、`toggleInterest()`、按鈕 JSX），放在說明文字與自由輸入框之間。其他瘦身後的版面不動。

- 已存的修課路徑與興趣會自動標為已選；不在選項清單中的已存興趣（例如自己打的「生成式 AI」）也會顯示成可取消的按鈕。
- 載入中、載入失敗、沒有班級時各有提示文字（沿用原文案）。
- 底部恢復「重新探索課程主題」（只對已設定過的帳號顯示）：重設瀏覽器裡的探索進度後進入興趣卡面，從第 1 張開始。
