# 探索頁起點選單：「沒有課程資料」改為「尚未建立比較資料」

日期：2026-11-24

## 背景

「從一門課出發」的起點選單中，不能當起點的課後面原本加註「（沒有課程資料）」。這個標記的實際原因是向量檔（ADR-035）裡沒有這個課號，與課程表有沒有這門課無關：本學期沒開的課仍可以只用課名比較，不會被標記。原本的文字容易讓人誤以為課程表缺資料。

使用者決定（2026-11-24）：改成「尚未建立比較資料」。

## 修改檔案

| 檔案 | 內容 |
| --- | --- |
| `client/src/pages/ExplorePage.jsx` | `FAVORITE_UNAVAILABLE_TEXT['no-course-vector']` 由「（沒有課程資料）」改為「（尚未建立比較資料）」 |

## 影響範圍

- 只改起點選單的一段標記文字；不改後端、API、排序或可用判定。
- 截至 2026-11-24，資料庫所有帳號的修課紀錄共 96 個課號，向量檔全部都有，D1249697 的 47 門起點全部可用，所以目前畫面上不會出現這個標記。之後匯入新課號時才可能出現，需重跑 `node server/scripts/courseExplorationEmbeddings.js --apply`。

## 測試與驗證

- 前端 `npm run lint`、`npm run build` 通過。
- 瀏覽器：用 D1249697 登入本機預覽，但這個瀏覽器被導向「隱私與資料使用」引導頁；為了不送出同意表單（可能寫入共用資料庫），沒有進入探索頁，**沒有在畫面上看到新標記**。改為確認開發伺服器實際提供的 `ExplorePage.jsx` 含「尚未建立比較資料」、不含「沒有課程資料」。console 只有登入前 `/api/auth/me` 的 401。
- 程式與文件中已無「沒有課程資料」字樣。
